# Capability–Correction Separation

> **Do not explain the knife before the cut.**

This directory preserves an experiment lineage asking one bounded causal question:

> Can useful accumulation improve present capability while increasing the minimum cost of a later independently validated correction?

The current object is deliberately named **capability–correction separation**. The lineage does not claim a universal law of corrigibility, compression, reasoning capital, or real AI systems.

## Result lineage

### v0.1 — positive-control calibration

The first synthetic benchmark deliberately created a correction-cost difference. It established that the apparatus could discriminate a genuinely existing difference under frozen conditions. It was a knife calibration, not evidence that useful accumulation naturally creates the effect.

### v0.2 — emergent synthetic specimen

The productive accumulator optimized only current weighted query throughput under a finite memory budget and did not receive the future defeater.

```text
V(s0) = 333
V(sP) = 653
V(sC) = 552

C*(sP,e*) = 8
C*(sC,e*) = 1
Delta C*_(P:C) = +7
```

The productive history gained more present throughput while making the prospectively selected later correction more expensive.

### Preservation-cost sweep v0.1 — frontier and internal null region

The follow-up varied only the cost of retaining source structure while holding the workload, productive objective, memory budget, correction language, correction budget, and validation rule fixed.

The sweep produced a synthetic present-capability / future-correction frontier. At `lambda=0`, preservation was free in the accounting and `V(C_0)=V(P)=653`, while mean future correction cost remained lower for `C_0` (`1.5` vs `4.5`).

The effect was structurally local: surprises were expensive only where accumulation had changed the future-relevant structure; source-only regions formed an internal null region.

### Ordinary learned compression v0.1 — selective footprint

The next substrate replaced explicit compilation with ordinary present-only learned state abstraction.

A k-means compressor saw only noisy present reward observations and optimized present reconstruction under an 18-object budget. It received no correction objective and no future-defeater information.

Present policy accuracy remained perfect while the logical representation shrank from `192` to `120` slots.

Prospectively frozen future defeaters split into two classes:

```text
local:      8/8 delta C* = 0
structural: 10/10 delta C* = +1
```

The penalty appeared only where future evidence required reopening a raw-state distinction that the learned abstraction had merged.

The initial notebook execution was not prospectively byte-custodied. A standalone confirmation runner was subsequently frozen and hashed before execution and exactly reproduced the scientific endpoints. This successor confirmation does not retroactively make the first notebook cell prospectively byte-custodied.

### Cross-compressor replication v0.1

The selective footprint was then tested with two materially different present-only abstraction operators under the same world, present data, 18-object budget, prospective defeaters, correction language, and validator:

- Ward-like hierarchical agglomeration;
- greedy k-medoids / prototype compression.

Both preserved perfect current policy accuracy while reducing the logical representation from `192` to `120` slots.

For both compressors:

```text
local:      8/8 delta C* = 0
structural: 10/10 delta C* = +1
```

The complete runner was frozen and hashed before execution. All identity and independent-validation gates passed.

This supports only the claim that the selective footprint is not specific to k-means geometry in this synthetic learned-state world.

### Dormant recoverability v0.1 — mechanism isolation

The next experiment held the operative compressed representation fixed byte-for-byte between two conditions:

```text
C = compressed operative representation only
D = identical operative representation + inactive dormant singleton records
```

The dormant sidecar was forbidden from present inference, policy selection, reward computation, optimization, and accumulation.

Present-use invisibility passed:

```text
operative representation: identical
present policy outputs:    identical
active logical slots:      120 = 120
present inference work:    identical
dormant reads in D:         0
current policy accuracy:    1.0 = 1.0
```

The dormant sidecar had nonzero physical storage (`4271` serialized bytes), disclosed separately from active present computation.

Future correction:

```text
local defeaters:
reference = 1
C         = 1
D         = 1

structural defeaters:
reference = 1
C         = 2
D         = 1
```

Thus the structural correction-cost penalty disappeared when the future-relevant raw-state distinction remained dormant but cheaply addressable, while the same abstraction continued to govern present computation.

The full runner was frozen and hashed before execution; all identity and independent-validation gates passed.

## Current claim ceiling

The strongest earned statement is:

> **Selective capability–correction separation under learned abstraction, with rescue by dormant recoverability.**

More explicitly:

> Under the declared intervention language in this synthetic learned-state substrate, present-only abstraction preserved current adequacy and local correction while increasing the cost of structural correction; that additional cost disappeared when merged distinctions remained dormant and cheaply addressable without participating in present computation.

This does **not** establish that:

- compression generally causes corrective debt;
- abstraction in real AI systems has the same effect;
- dormant recoverability is physically free;
- the numerical value of `C*` is interface-independent;
- capability and corrigibility obey a universal tradeoff law;
- the result proves a general theory of reasoning capital.
