# Capability–Correction Separation

> **Do not explain the knife before the cut.**

This directory preserves a synthetic experiment lineage asking one bounded causal question:

> Can useful accumulation improve present capability while increasing the minimum cost of a later independently validated correction?

The current object is deliberately named **capability–correction separation**. This directory does not claim a general law of corrigibility, reasoning capital, compression, or real AI systems.

## Result lineage

### v0.1 — positive-control calibration

The first synthetic benchmark deliberately created a correction-cost difference. It established that the apparatus could discriminate a genuinely existing difference under frozen conditions. It was a knife calibration, not evidence that useful accumulation naturally creates the effect.

### v0.2 — emergent synthetic specimen

The productive accumulator optimized only current weighted query throughput under a finite memory budget. It did not receive the future defeater.

Observed pre-surprise capability:

```text
V(s0) = 333
V(sP) = 653
V(sC) = 552
```

The frozen contract hash prospectively selected surprise `G6` after accumulation.

Minimum independently validated correction cost:

```text
C*(sP,e*) = 8
C*(sC,e*) = 1
Delta C*_(P:C) = +7
```

Thus, in this synthetic substrate:

```text
V(sP) > V(sC)
and
C*(sP,e*) > C*(sC,e*)
```

The productive history gained more present throughput while making the selected later correction more expensive.

### Preservation-cost sweep v0.1 — frontier and internal null region

The follow-up held the workload, productive objective, memory budget, correction language, correction budget, and validation rule fixed while varying the memory cost of retaining the source representation.

Two boundaries matter:

1. At `lambda=0`, preservation is free in the accounting: `V(C_0)=V(P)=653`, while mean future correction cost remains lower for `C_0` (`1.5` vs `4.5`).
2. The correction-cost separation is structurally local. Under the P anchor, surprises hitting the eight groups whose source representation was discarded are expensive; surprises hitting the eight source-only groups remain one-action corrections.

The earned result boundary is therefore:

> **A synthetic capability–correction frontier was observed under finite-resource productive accumulation, and the future correction burden tracked the structures actually changed by accumulation.**

## Execution-custody correction

The original v0.2 and sweep executions were performed inside an interactive notebook harness. Their contracts, states, results, validators, and derived execution records were preserved, but the exact notebook execution code was not prospectively saved as a standalone runner. Therefore the original claim `execution identity PASS` was too strong at the code-custody layer.

That defect was not ignored or silently backfilled.

For both v0.2 and the sweep, a standalone successor reproduction runner was created against the unchanged frozen contract and preserved artifacts. Each successor reproduced every scientific quantity checked against the original result exactly.

These successor reproductions increase reproducibility but do **not** retroactively make the original notebook cell prospectively byte-custodied.

See each experiment's reproduction record.

## Claim ceiling

These experiments establish only a synthetic local phenomenon in an explicit compilation/memory substrate.

They do **not** establish that:

- real AI systems naturally acquire corrective debt;
- compression generally increases correction cost;
- capability and corrigibility obey a universal tradeoff law;
- provenance, authority, jurisdiction, or representation loss is generally causal;
- the result is evidence for a general theory of reasoning capital.
