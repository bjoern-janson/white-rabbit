## 1. Starting boundary

The preceding capability–correction lineage established a selective synthetic correction-cost effect under learned abstraction and showed that dormant recoverability could remove the additional structural correction cost while leaving present computation unchanged.

The mathematical boundary was then stated as:

```math
\boxed{W\xrightarrow{p}X\xrightarrow{q}Q.}
```

For an operation `e:X->Y`, exact representability through `Q` requires:

```math
\boxed{e\text{ descends through }q\iff \ker q\subseteq\ker e.}
```

But this assumes that the consequential distinction already exists in `X`.

If a world-level operation `e*` does not factor through `p:W->X`, then no refinement of `q` can recover that distinction from `X` alone.

The frozen lower boundary was therefore:

```math
\boxed{
\textbf{How does consequence induce construction of a distinction that the current state space cannot express?}
}
```

The ARC lineage below was built to pressure that boundary rather than extend it by vocabulary.

See [`../capability-correction-separation/OPERATION_RELATIVE_ADEQUACY.md`](../capability-correction-separation/OPERATION_RELATIVE_ADEQUACY.md).

## 2. Synthetic instrument ladder


This established a controlled mechanism for **revision after contradiction**. It did not establish autonomous construction of a genuinely new state vocabulary.

## 3. First real ARC specimen — `ft09`

### 3.1 Source-firewalled acting phase

A first public ARC-AGI-3 run used `ft09-0d8bbf25`, seed `0`.

The acting phase saw only rendered frames and the exposed action interface. The environment implementation was inspected only after the run was deliberately stopped at Level 3.

Run summary:

```text
actions executed: 12
levels completed: 2 / 6
local public scorecard: 14.285714
```

This was not a Kaggle submission and not a hidden-set result.

#### t=1 — action-affordance contradiction

The acting model predicted that a tiny clue cell was directly editable. A click produced zero changed frame cells.

The model reopened minimally:

```text
mini-cell editable
        ↓ falsified
mini is clue; surrounding coarse cell editable
```

The revised action model worked and Level 1 completed.

#### t=6 — semantic contradiction hidden by success

The inherited Level-1 semantic theory had promoted a local observation into an absolute mapping:

```text
0 -> 8
2 -> 9
```

At the first Level-2 action it predicted:

```text
9 -> 8
```

Reality returned:

```text
9 -> 12
```

The semantic commitment was already false.

However, the first live harness had preplanned the remaining Level-2 actions as a batch. Those positional actions still completed Level 2 successfully.

The real specimen was therefore:

```math
\boxed{
\text{behavioral success}\not\Rightarrow\text{mechanistic correctness}
}
```

and more specifically:

```math
\boxed{
\text{a falsified internal commitment can remain behaviorally adequate for a while.}
}
```

### 3.2 Source-side audit

The post-run audit showed why.

The active palette changes by level:

```text
Level 1: [9, 8]
Level 2: [9, 12]
Level 3: [8, 12]
```

The portable clue mechanism is relational rather than an absolute color lookup:

```text
clue entry 0       -> neighbor matches the clue-center color
clue entry nonzero -> neighbor differs from the clue-center color
```

The acting model had learned an over-specific Level-1 coincidence where a relation was required.

Level 2 falsified the color semantics immediately while preserving enough positional structure for the same action sequence to succeed.

This is a real public-ARC specimen of:

```math
\boxed{
\text{partial mechanism falsification}
+
\text{continued behavioral success}
}
```

The first harness could not cleanly attribute failure to reopen because post-action evidence was not returned to policy selection before the next batched action.

## 9. Current diagnostic map

The lineage now separates at least three barriers before recovery and validation:

### Barrier 1 — observational discrimination

If two world states are invariant under every available observational/interventional policy:

```math
w_1\equiv_\Pi w_2,
```

then no algorithm using only those transcripts can evidence-identify the distinction.

### Barrier 2 — state construction / objectification

The information may be present in principle, yet the system may fail to construct the units, variables, events, or relations required to make the consequential distinction evaluable.

This is the `m0r0` failure locus.

### Barrier 3 — representation refinement

The relevant distinction exists in `X`, but the operative representation `Q` collapses it.

This is the regime governed by the operation-relative factorization boundary.

The current diagnostic order is therefore:

```math
\boxed{
\text{observability}
\rightarrow
\text{state construction}
\rightarrow
\text{representation / quotient}
\rightarrow
\text{factorization}
\rightarrow
\text{recovery}
\rightarrow
\text{resource reachability}
\rightarrow
\text{intervention}
\rightarrow
\text{validation}
}
```

Do not substitute one failure locus for another.
