# Frozen Frontier — Construction Capability

> **RESEARCH FRONTIER — FROZEN**

This note records the terminal boundary reached after the ARC reopening lineage, the `ft09` positive controls, the development-contaminated C2 mechanism demonstration, and the untouched prospective `m0r0` failure.

It adds no new experiment, primitive, ontology, or architecture.

The current separation is:

```math
\boxed{
\text{selection change}
\neq
\text{reachability change}
\neq
\text{construction-capability change}
}
```

These must not be collapsed into one claim of adaptation.

---

## 1. Three distinct post-consequence changes

Suppose a system has a pre-consequence construction mechanism that induces a family of state constructions `\mathcal C_t` under a declared interface and resource bound.

After consequential evidence, at least three different things can happen.

### Selection change

A construction was already available and reachable, but the system previously did not choose it.

```math
C^\star\in\mathcal C_t
```

before and after consequence; only selection changes.

### Reachability change

A constructor already existed in the machine, but consequence changes whether the system can access, activate, or reach it under the operative control path.

The capability may be newly reachable without being newly constructed.

### Construction-capability change

The strongest frontier claim requires that a construction family unavailable to the declared pre-consequence machinery becomes available afterward:

```math
\boxed{
C^\star\notin\mathcal C_t
\quad\land\quad
C^\star\in\mathcal C_{t+1}
}
```

where `C^\star\notin\mathcal C_t` means more than "the system did not happen to emit it."

It means the earlier system lacked an admissible path to that construction under the declared machinery, interface, and resource bound.

Only this third case approaches the current deep frontier.

---

## 2. Dormant-constructor attack

A future positive must survive at least two independent null hypotheses.

```math
H_0^{(1)}:
\text{the constructor was available before consequence but was not selected}
```

and:

```math
H_0^{(2)}:
\text{the constructor already existed and was reachable in principle but simply never surfaced}
```

A large dormant library of hand-written constructors must not be allowed to masquerade as open-ended construction-space change.

Therefore preserve:

```math
\boxed{
\text{newly used}
\neq
\text{newly reachable}
\neq
\text{newly constructible}
}
```

The relevant custody question is:

> **Was the capability constructed, or was dormant authority merely surfaced?**

This challenge is not solved here. It is a required adversarial control on any future positive result.

---

## 3. Evidentiary burden for a future positive

A credible construction-capability result would need, at minimum:

1. an auditable pre-consequence machine;
2. a declared interface and resource bound;
3. evidence that `C^\star` is unavailable to the pre-consequence construction machinery, not merely unobserved;
4. a consequential event that changes the operative system;
5. post-consequence availability of `C^\star`;
6. prospective validation that the new construction corresponds to a real environmental distinction;
7. future operational use of that distinction;
8. explicit attacks on selection-only and dormant/reachability explanations.

The desired causal shape is:

```math
\boxed{
\text{consequence}
\rightarrow
\text{construction-capability change}
\rightarrow
\text{new state construction}
\rightarrow
\text{prospective evidence}
\rightarrow
\text{future use}
}
```

A post-hoc novel description is insufficient.

A newly selected dormant constructor is insufficient.

A newly reachable but pre-existing constructor is insufficient for the deepest claim.

---

## 4. Conservative ARC interpretation

ARC fixes the external observation/action grammar sufficiently strongly to separate internal state-construction questions from external sensor/actuator invention.

For black-box agents, preserve:

```math
\boxed{
\text{new behavior}
\not\Rightarrow
\text{new state dependence}
\not\Rightarrow
\text{new representational capability}
}
```

A useful behavioral pressure test is possible when histories that were previously operationally aliased become systematically distinguished after consequence.

If:

```math
h_1\sim_t h_2
```

but later:

```math
h_1\not\sim_{t+k}h_2,
```

and the new behavioral distinction is grounded in a real environmental difference and prospectively useful, then the auditor has evidence for changed usable state dependence.

That does **not** by itself prove explicit state-variable invention or construction-capability change.

The stronger claim still requires pre/post construction-capability comparison and the dormant-constructor challenge.
