# AI 2027 Placement Hypothesis

Status: `DERIVED_PROGRAM_SYNTHESIS / PLACEMENT_HYPOTHESIS / NON_CANONICAL / NON_AUTHORIZING / NOT_EMPIRICAL_EVIDENCE`

This note records a cross-domain placement hypothesis for White Rabbit relative to the AI 2027 research-automation feedback loop.

It does **not** modify the frozen White Rabbit program definition, the White Rabbit conceptual freeze, Gate 7, or any scientific result. It does not establish that White Rabbit exists, that AI R&D currently contains this mechanism, or that any recursive-improvement multiplier has been demonstrated.

The canonical White Rabbit program definition remains [`program/WHITE_RABBIT.md`](WHITE_RABBIT.md). The current conceptual freeze remains [`program/WHITE_RABBIT_CONCEPTUAL_FREEZE_V0_1.md`](WHITE_RABBIT_CONCEPTUAL_FREEZE_V0_1.md).

## Placement claim

AI 2027 models a feedback loop of the rough form:

```text
better AI
    -> AI-for-AI R&D
    -> higher effective AI R&D throughput
    -> better AI
```

White Rabbit is not proposed here as another dated prediction or milestone inside that loop.

The placement hypothesis is that a mature White Rabbit capability would instead behave like a **state variable inside the mechanism that generates the loop's R&D throughput**.

Introduce:

```text
R_t = stock of validated, reusable, correctable computational leverage
```

Then a schematic AI-R&D production relation could contain:

```text
R&D_throughput_t = F(A_t, H_t, K_t, compute_t, R_t)
```

where the other terms may stand for AI capability, human contribution, other capital or infrastructure, and available compute. This equation is illustrative only. It is not a fitted or established model.

A minimal stock update is:

```text
R_{t+1}
    = R_t
    + newly validated reusable structures
    - revoked or obsolete structures
```

The subtraction term matters. `R_t` is not intended to mean an ever-growing pile of frozen shortcuts.

## Base Rabbit channel

The first-order placement hypothesis is:

```text
R_t increases
    -> repeated R&D work per useful result decreases
    -> effective R&D throughput increases
```

or schematically:

```text
R_t up
    -> C_R&D/use down
    -> useful R&D throughput up
```

This is the **Base Rabbit** channel.

Its role in an AI-2027-style system would be to contribute to an AI-R&D progress multiplier from the efficiency side: past successful computation becomes reusable leverage, so future research does not need to repurchase all of the same computational work.

This channel does not require the underlying model to become intrinsically smarter during the same interval. In principle, the same model and hardware could yield more useful research throughput if a larger fraction of already-earned computational structure can be reused safely.

## Compounding Rabbit channel

The stronger placement hypothesis is:

```text
R_t
    -> Delta Phi_{t+1} > 0
    -> future reusable structure becomes cheaper or more effective to produce
    -> R_{t+1}
```

where `Phi` is the existing White Rabbit program-level construct for the capacity and economics of discovering, validating, realizing, monitoring, and revising useful future computational structures.

This gives a possible additional feedback edge:

```text
R_t
    -> Phi_{t+1}
    -> R_{t+1}
    -> Phi_{t+2}
    -> ...
```

This is the **Compounding Rabbit** channel.

The distinction is important:

```text
Base Rabbit:
    reusable leverage makes current R&D cheaper or more productive

Compounding Rabbit:
    reusable leverage improves the future process that creates more reusable leverage
```

Compounding is a strictly stronger empirical burden in the current White Rabbit architecture. It is not required for minimum Rabbit status and is not established by current evidence.

## Correctability requirement attached to R_t

The intended state variable is not:

```text
R_t = accumulated shortcuts
```

It is closer to:

```text
R_t =
    reusable leverage
    + provenance
    + preserved evidential access
    + operative revision authority
```

The exact representation of these terms is not fixed by this note. The point is architectural: accumulated leverage should remain challenge-permeable and revisable rather than becoming an increasingly entrenched body of opaque assumptions.

A candidate structure that is reusable but cannot be invalidated or replaced when contrary evidence arrives is not the White Rabbit object described here.

## AI-2027 placement diagram

The hypothesized placement is:

```text
frontier AI
    -> AI-for-AI R&D
    -> White Rabbit substrate / R_t
    -> lower marginal R&D cost per useful result
    -> higher effective R&D throughput
    -> better AI
    -> ...
```

with an optional stronger edge:

```text
R_t -> Delta Phi_{t+1} > 0
```

only for the Compounding Rabbit case.

Therefore the concise placement claim is:

> **AI 2027 models the feedback loop; White Rabbit is a candidate state variable that could make that loop cheaper, cumulative, and—if its correction channel works—less epistemically brittle.**

## Why this sits beneath the R&D multiplier

AI 2027 explicitly uses an **AI R&D progress multiplier**: a comparison between algorithmic/software progress with AI assistance and a counterfactual without that assistance.

White Rabbit would not equal that multiplier. It would be one possible contributor to it.

The proposed contribution is:

```text
past successful computational work
    -> validated reusable structure
    -> less repeated future work
    -> more useful research per unit resource
```

If the stronger compounding arrow also held, White Rabbit could additionally change the slope of the feedback loop by improving the economics of producing future reusable leverage.

## Evidence ladder

Do not collapse the following claims:

```text
1. a reusable structure is used
2. the structure saves local work
3. the structure lowers lifecycle cost after acquisition, observation, and revision costs
4. the structure improves the future economics of producing additional reusable structure
```

For current White Rabbit notation:

```text
Delta W_gen < 0
    does NOT imply
Delta C_H < 0
    does NOT imply
Delta Phi > 0
```

This is the central authority boundary for the placement hypothesis.

## Gate 7 firewall

Gate 7 remains a local assay and does not establish this placement mechanism.

In particular:

```text
local N_generated difference
    != lifecycle leverage
    != reusable computational stock R_t
    != AI-R&D multiplier
    != Delta Phi > 0
```

No current Gate 7 result may be promoted into evidence that White Rabbit accelerates AI R&D or recursive improvement.

## What evidence would eventually be needed

Moving from placement hypothesis to supported mechanism would require separate evidence for at least:

```text
reusable structure identity
independent reproduction
preserved capability
local work reduction
lifecycle amortization under a constituted baseline
challenge permeability
operative revision
```

and, for the compounding claim specifically:

```text
R_t
    -> measurable improvement in future discovery / validation / realization / monitoring / revision economics
```

The last arrow must be measured rather than inferred from adoption or local performance.
